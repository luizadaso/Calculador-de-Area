# 🟰 Calculador de Área de Formatos Geométricos

## Descrição

Este projeto foi desenvolvido com o objetivo de praticar conceitos de Programação Orientada a Objetos (POO) em Java, 
especialmente o uso de interfaces e polimorfismo.

A aplicação utiliza a interface `AreaCalculator` como um contrato para o cálculo da área de figuras geométricas, 
permitindo que diferentes classes implementem sua própria lógica de cálculo de forma organizada e desacoplada.

## Tecnologias & Ferramentas

- Java 21
- Programação Orientada a Objetos (POO)
- Git
- GitHub
- IntelliJ IDEA

## Funcionalidades

- Cálculo da área de figuras geométricas.
- Implementação de contratos através de interfaces.
- Estrutura extensível para inclusão de novas figuras.
- Demonstração prática de polimorfismo.
- Código organizado seguindo boas práticas de orientação a objetos.

## Conceitos Aplicados

### Interface

Definição de um contrato através da interface `AreaCalculator`, garantindo que todas as classes implementem o método de cálculo de área.

### Polimorfismo

Permite que diferentes objetos sejam tratados por meio da mesma interface, oferecendo flexibilidade e facilidade de manutenção.

### Abstração

Separação entre a definição do comportamento e sua implementação concreta.

### Encapsulamento

Organização das responsabilidades em classes específicas para facilitar a leitura e manutenção do código.
